### Sobre Mí

Soy programador **Full Stack** en **PaxaPOS**, un sistema POS multicomercio que usan comercios gastronómicos, un gremio y un municipio. Trabajo de punta a punta: interfaces en SvelteKit y TypeScript, y servicios en Python que imprimen tickets y facturas en los locales de los clientes.

- **Frontend:** SvelteKit, Svelte 5, TypeScript, React y Tailwind CSS.
- **Backend:** Python (FastAPI), Node.js, RabbitMQ, MQTT y WebSockets.
- **IA aplicada:** prompt engineering, skills e instrucciones para agentes (Claude Code, GitHub Copilot), MCP y documentación para LLM.
- **Datos e infraestructura:** SQL (Oracle, SQLite/Turso), MongoDB, Docker, nginx y GitHub Actions.
